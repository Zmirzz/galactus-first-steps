# 1.1.0 — 2026-10-03

- Heraldul este Silver Surfer: model atletic articulat, textură argintie cu reflexe pictate, postură de surfing, placă cu vârfuri îngustate, margini luminoase și urmă cosmică.
- Heraldul se apropie de jucător și oprește deplasarea în raza de interacțiune, pentru folosirea sigiliului. Identitatea este actualizată și în evenimentele salvate anterior.
- Galactus: armură stratificată, cască cu extensii înclinate și canale, față detaliată, mănuși și genunchiere, respirație și articulații animate.
- Măști luminoase pentru ochi și energie; atlase separate de 512 px cu suprafețe pictate individual.
- Introducere cu titluri și dialog etapizat; falie circulară la sosire; două semnale sonore sintetizate originale.
- Titlurile, pregătirea și dialogul Silver Surfer au traduceri românești și englezești.
- Păstrează identificatorul `galactus:herald` pentru compatibilitate cu salvările 1.0.0. Cerințele rămân Minecraft 1.21.1 / Fabric / Java 21.

# 1.0.0 — 2026-10-03

- Silver herald warning and configurable preparation countdown.
- Colossal custom Galactus, floating cosmic anchors and silver surfboard herald.
- Persistent invasion, hunger, telegraphed strikes, raids and configurable terrain consumption.
- Three survival endings: Ultimate Nullifier, dimensional portal, herald redemption; direct combat also supported.
- Five crafting recipes, recipe-book unlocks, in-game survival journal and world-savior reward.
- Server configuration, administrative commands, English and Romanian item names.
- Tested with Minecraft 1.21.1, Fabric Loader 0.16.14, Fabric API 0.116.6+1.21.1, Java 21.
